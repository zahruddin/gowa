🚀 Project Brief: GOWA (Go WhatsApp API) - Enterprise EditionStatus Proyek: Fase Pengembangan ModularTarget Platform: Android (Termux) & Linux (Ubuntu/WSL)Main Engine: whatsmeow (Golang Binary Socket)1. Visi UtamaMembangun sebuah gateway WhatsApp mandiri yang mampu mengelola banyak akun secara simultan dalam satu aplikasi (single binary), menyediakan jalur integrasi melalui REST API, dan mendukung pengiriman massal berbasis data eksternal (Excel).2. Arsitektur Folder & TeknologiSistem menggunakan Clean Architecture untuk memastikan kestabilan resource di perangkat Android.Language: Go (Golang) 1.21+Database: SQLite (WAL Mode) untuk konkurensi tinggi.Library Utama: * whatsmeow: Protokol WhatsApp.excelize/v2: Pemrosesan file Excel (.xlsx).chi atau net/http: Router API yang ringan.tailwind: UI Admin Panel (CDN).3. Fitur Utama (Expanded)A. Multi-Session ManagementDynamic Client: Menambah dan menghapus sesi WA tanpa mematikan aplikasi.Session Isolation: Setiap sesi memiliki database store sendiri namun dikelola oleh satu SessionManager.Status Dashboard: Monitor baterai, status koneksi, dan nama perangkat di tiap sesi.B. Advanced Bulk Sender (Excel Support)Excel Parsing: Mengunggah file .xlsx dan memetakan kolom nomor serta pesan.Variable Injection: Mendukung tag dinamis seperti Halo {nama}, di mana {nama} diambil dari kolom Excel.Smart Delay: Jeda waktu acak (misal 5-15 detik) antar pesan untuk meminimalisir risiko banned.Real-time Progress: Progress bar pengiriman di halaman web.C. REST API & WebhookToken-Based API: Setiap sesi memiliki API_TOKEN unik. Request tanpa token yang valid akan ditolak (Middleware Auth).Multimedia API: Endpoint khusus untuk mengirim gambar, dokumen, dan PDF (via link atau upload).Inbound Webhook: Meneruskan pesan masuk ke URL luar dalam format JSON secara asinkron (Goroutine).D. Konfigurasi Bot via Chat (Whitelist)Nomor yang terdaftar di Whitelist dapat mengirim perintah seperti:#setwebhook [url]#addkatalog [keyword]@[pesan]#status (Cek penggunaan RAM/CPU HP)4. Skema Database (Pembaruan)TabelFungsisessionsMenyimpan session_id, api_token, dan webhook_url.katalogData auto-response (keyword vs details).whitelistDaftar nomor admin yang punya akses kontrol via chat.bulk_jobsRiwayat pengiriman massal (status: success/failed).usersAkun login untuk masuk ke Web Panel.5. Roadmap Pengembangan TerbaruFase 1: Core Multi-Session (Jantung Sistem)Implementasi SessionManager di internal/bot/.Migrasi koneksi SQLite tunggal menjadi terpusat.Fase 2: Web Panel & AuthDashboard dengan Tailwind CSS.Sistem Login Admin dan manajemen Session Token.Fase 3: Integrasi Excel & MediaFitur upload Excel dan logika looping pengiriman.Optimasi pengiriman file media agar tetap ringan di RAM Android.Fase 4: Webhook & WhitelistPenambahan jalur keluar (outbound) data ke server lain.Logika perintah admin melalui chat WhatsApp.6. Strategi Optimasi Android (Termux)Agar proyek ini tidak memberatkan HP:Garbage Collection: Menjalankan runtime.GC() secara berkala jika session > 5.No-Browser: Tetap menggunakan socket, dilarang menggunakan library berbasis Chromium.Wake-Lock: Memastikan Termux tetap berjalan di background meskipun layar mati.
