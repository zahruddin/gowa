Send Text Message

Send a text message to a specific number using a connected session.

POST /api/send-text

Headers

Content-Type: application/json
X-API-Token: <YOUR_SESSION_API_TOKEN>

Note: You can find your X-API-Token by clicking "Detail" on your session card.

Request Body (JSON)

{
  "session_id": "store1",
  "to": "6281234567890",
  "message": "Hello from GOWA API!"
}
